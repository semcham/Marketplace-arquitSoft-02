# Marketplace-arquitSoft-02

# Marketplace de Productos para Mascotas

## Integrantes

- TORRES MORALES SEM CHAM

## Descripción

Sistema web tipo **Marketplace** orientado a la comercialización de productos
para mascotas. La plataforma permitirá gestionar y consultar productos,
categorías, vendedores y compradores, proporcionando una estructura que
facilite la interacción entre los usuarios y los proveedores de productos
para mascotas.

El proyecto se desarrolla con fines académicos y tiene como principal enfoque
el **análisis y diseño de la arquitectura de software**, considerando los
requisitos funcionales, atributos de calidad, restricciones y decisiones
arquitectónicas del sistema.

## Caso de Estudio

**GoPet** se utilizará como referencia funcional para analizar las
características y funcionalidades relacionadas con un Marketplace de productos
para mascotas.

La referencia permitirá identificar necesidades y comportamientos del dominio,
sin pretender replicar directamente su implementación.

## Objetivo

Diseñar una arquitectura de software para un Marketplace de productos para
mascotas que permita organizar sus principales componentes, funcionalidades y
requisitos de calidad, estableciendo una base estructurada para su posterior
desarrollo.
