# Historias de usuario

## 1. Descripción

Las historias de usuario describen las principales necesidades de los
actores que interactúan con el marketplace de productos para mascotas.

Se utiliza el formato:

> Como [actor], quiero [acción], para [beneficio].

## 2. Historias de usuario

| ID   | Historia de usuario                                                                                                               |
| ---- | --------------------------------------------------------------------------------------------------------------------------------- |
| HU01 | Como cliente, quiero buscar y consultar productos, para encontrar el producto que necesito.                                       |
| HU02 | Como seller, quiero registrar y gestionar mis productos, para ofrecerlos a los clientes.                                          |
| HU03 | Como cliente, quiero gestionar los productos de mi carrito, para preparar los productos que deseo comprar.                        |
| HU04 | Como cliente, quiero realizar un pedido con los productos de mi carrito, para completar mi compra.                                |
| HU05 | Como administrador, quiero gestionar los sellers de la plataforma, para administrar a los vendedores registrados.                 |
| HU06 | Como cliente, quiero consultar mis pedidos y su estado, para conocer el estado de mis compras.                                    |
| HU07 | Como cliente, quiero realizar el pago de mi pedido, para completar la compra de los productos seleccionados.                      |
| HU08 | Como seller, quiero consultar la información de mis ventas, para realizar el seguimiento de las operaciones realizadas.           |
| HU09 | Como administrador, quiero supervisar las operaciones de la plataforma, para mantener un adecuado funcionamiento del marketplace. |
| HU10 | Como cliente, quiero consultar la disponibilidad de los productos, para conocer si puedo realizar la compra.                      |
| HU11 | Como cliente, quiero recibir información sobre la entrega de mi pedido, para conocer el estado de mi envío.                       |
| HU12 | Como cliente, quiero obtener el comprobante de mi compra, para disponer de la constancia de la operación realizada.               |

## 3. Actores relacionados

- **Cliente:** HU01, HU03, HU04, HU06, HU07, HU10, HU11, HU12.
- **Seller:** HU02, HU08.
- **Administrador:** HU05, HU09.
- **Pasarela de pago:** relacionada con HU07.
- **Servicio de envío:** relacionado con HU11.
- **Servicio de facturación:** relacionado con HU12.
- **ERP:** relacionado con HU01 y HU10.
